## Coolify deploy
1. Application → **Persistent Storage** → Add: Destination path `/app/data`  ← **අනිවාර්යයි** (නැත්නම් deploy කරන හැම පාරම ලිස්ට් එක මැකෙනවා)
2. **Environment Variables** → `HOUSEHOLD_KEY` = ගෙදර අයට කියන කෝඩ් එකක් (උදා: වචන 2-3ක්)
3. Build pack: Dockerfile, port 3000 → **Redeploy**
4. පරණ ලිස්ට් එක: ⚙️ → 📥 Restore එකට පරණ `/api/state` JSON එක paste කරන්න (පරණ කාණ්ඩ නම් auto හැදෙනවා)

ෆෝන්වලට: `https://<link>/#key=<කෝඩ්-එක>` ලින්ක් එක එක පාරක් ඇරියම කෝඩ් එක මතක තියාගන්නවා. APK එකේදී කෝඩ් එක එක පාරක් type කරන්න.
