## v2 එකේ අලුත් දේවල්
- **දත්ත නැතිවෙන්නේ නැහැ:** මුළු ලිස්ට් එකම නොයවා "හාල් −0.5" වගේ වෙනස විතරයි යවන්නේ. ඒ නිසා ෆෝන් දෙකක් එකවර වෙනස් කළත් දෙකම ඉතිරි වෙනවා.
- **Offline:** නෙට් නැතිව කරන වෙනස්කම් ෆෝන් එකේ පෝලිමක තියාගෙන, නෙට් ආපුවාම auto යවනවා.
- **ගෙදර කෝඩ් එක:** `HOUSEHOLD_KEY` දැම්මාම කෝඩ් එක දන්න අයට විතරයි ලිස්ට් එක බලන්න පුළුවන්.
- **Backups:** දවසකට එක backup එකක් (දවස් 30). ⚙️ → Backup එකෙන් කොපියක් ගන්නත් පුළුවන්.
- **↩️ අහෝසි:** වැරදිලා − එබුවොත්, උයන්න එබුවොත්, සාප්පු ඉවරයි එබුවොත් ආපහු හරවන්න පුළුවන්.
- **ඉතිහාසය:** කවුද මොනවද වෙනස් කළේ කියලා (📅 මාසය ටැබ් එකේ). ⚙️ එකේ ෆෝන් එකට නමක් දාන්න.
- **සාප්පු ලිස්ට්:** ගත්ත ප්‍රමාණය වෙනස් කරන්න පුළුවන්, WhatsApp එකට යවන්න පුළුවන්.
- හැම බඩුවකටම "අඩුයි" කියන සීමාව දාන්න පුළුවන්. g බඩුවලට +/− 25g/100g වලින්.

- මාස සාරාංශය: මුල / ගත්තා / පාවිච්චි / ඉතිරි (කලින් ගත්ත බඩුත් පාවිච්චියෙන් අඩු වුණා).

## Coolify deploy
1. Application → **Persistent Storage** → Add: Destination path `/app/data`  ← **අනිවාර්යයි** (නැත්නම් deploy කරන හැම පාරම ලිස්ට් එක මැකෙනවා)
2. **Environment Variables** → `HOUSEHOLD_KEY` = ගෙදර අයට කියන කෝඩ් එකක් (උදා: වචන 2-3ක්)
3. Build pack: Dockerfile, port 3000 → **Redeploy**
4. පරණ ලිස්ට් එක: ⚙️ → 📥 Restore එකට පරණ `/api/state` JSON එක paste කරන්න (පරණ කාණ්ඩ නම් auto හැදෙනවා)

ෆෝන්වලට: `https://<link>/#key=<කෝඩ්-එක>` ලින්ක් එක එක පාරක් ඇරියම කෝඩ් එක මතක තියාගන්නවා. APK එකේදී කෝඩ් එක එක පාරක් type කරන්න.

## APK
- දැනට install කරලා තියෙන APK (v1.7) එකම අලුත් app එක auto load කරනවා — අලුතෙන් install කරන්න ඕන නැහැ.
- අලුත් APK (v2.0): GitHub → Actions → **Build APK**. විස්තර `android/BUILD-NOTES.md`.

## Files
- `server.js` — Node server (packages නැහැ). `public/core.js` — server සහ app දෙකම පාවිච්චි කරන logic.
- `public/index.html` — app එක. `public/sw.js` — offline cache. `seed.json` — මුල් බඩු ලිස්ට් එක.
