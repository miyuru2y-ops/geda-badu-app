# ගෙදර බඩු — Sinhala Household App

ෆෝන් 3ම එකම ලිස්ට් එකක් පාවිච්චි කරනවා. එක ෆෝන් එකක වෙනසක් කළාම
තත්පර කීපයකින් අනිත් දෙකටත් පේනවා (ඇප් එක තත්පර 5කට වරක් සර්වර් එකෙන් අලුත් දත්ත ගන්නවා).

## වැදගත්: Git එකෙන් සින්ක් වෙන්නේ කොහොමද?

Git එකේ තියෙන්නේ මේ කෝඩ් එක විතරයි. ෆෝන් 3කින් කෙලින්ම Git එකට
දත්ත ලිව්වොත්, දෙන්නෙක් එකවර ලිව්වොත් conflict වෙලා ලිස්ට් එක
නැතිවෙන්න පුළුවන්. ඒ නිසා හරි ක්‍රමය මේකයි:

1. කෝඩ් එක GitHub එකට push කරනවා.
2. Coolify එකෙන් ඒ repo එක deploy කරනවා (ඔයාගේ VPS එකේ).
3. ෆෝන් 3ම එකම වෙබ් ලින්ක් එකෙන් ඇප් එක අරිනවා — දත්ත තියෙන්නේ
   සර්වර් එකේ එක තැනක (`data.json`), ඒ නිසා හැමෝම එකම ලිස්ට් එක දකියි.

## 1. GitHub එකට දාන්න (ඔයාගේ PC එකෙන්)

```bash
cd geda-badu-app
git init
git add .
git commit -m "Geda badu app v1"
git branch -M main
git remote add origin https://github.com/miyuru2y-ops/geda-badu-app.git
git push -u origin main
```

Repo එක GitHub එකේ හදන්න කලින්: github.com → New repository →
නම `geda-badu-app` → Public → Create (README එකක් එකතු කරන්න එපා,
මේ folder එකේ තියෙන ඒවාම push වෙනවා).

## 2. Coolify එකෙන් deploy කරන්න (bostsite එක වගේම)

1. Coolify dashboard → New Resource → Application
2. Source: Public Repository, URL: `https://github.com/miyuru2y-ops/geda-badu-app`
3. Branch: `main`, Build Pack: **Dockerfile** (Dockerfile එක මේ repo එකේම තියෙනවා)
4. Port: `3000`, Deploy ඔබන්න
5. ලැබෙන ලින්ක් එක (උදා: `https://geda-badu-xxxx.sportantics.com`)
   ෆෝන් 3ටම WhatsApp කරන්න

## 3. ෆෝන් එකට Install කරන්න

ෆෝන් එකේ Chrome/Safari එකෙන් ලින්ක් එක අරින්න →
මෙනුව → **Add to Home Screen** / **Home screen එකට එකතු කරන්න**.
ඊට පස්සේ සාමාන්‍ය ඇප් එකක් වගේ icon එකෙන් අරින්න පුළුවන්.

## ඇප් එකේ තියෙන දේවල්

- සිංහලෙන්ම UI, ලොකු බොත්තම්
- ඔයා දුන්න බඩු 24ම දැනටමත් ඇතුළේ (ප්‍රමාණත් එක්ක)
- `🍳 අද උයන්න` — දිනපතා උයන්න යන ප්‍රමාණයෙන් (හාල් 0.5kg, පරිප්පු 0.1kg
  වගේ) එකවර අඩු කරනවා
- හැම බඩුවකටම `✓ පාවිච්චි කළා`, `− / +`, සංස්කරණය, අයින් කිරීම
- `⚠️ අඩු බඩු` ටැබ් එක — තොගය අඩු ඒවා
- `🛒 සාප්පු ලිස්ට්` — 25 වෙනිදාට ඒකම උඩින් පෙන්නනවා,
  “ගත්තා ✓” ඔබපුවාම තොගයට එකතු වෙනවා
- `📅 මාස අවසානය` — මාසේ මුල තිබුණ, පාවිච්චි කළ, ඉතිරි ටික
- `➕ අලුත් බඩුවක්` — නම, කාණ්ඩය, ඒකකය, ප්‍රමාණ දාලා එකතු කරන්න
